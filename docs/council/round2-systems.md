# Round 2 - Systems engineering review

**Decision:** repair browser trust/liveness first; retain DOM filtering; add independent service-owned DNS/WFP; prototype capture concurrently without shipping an unmeasured guarantee.

Reviewed all three round-1 papers and `CLAUDE.md` against checkout `fa70208`. Evidence is static inspection plus in-memory execution of extracted TypeScript predicates/handlers/state transitions. No installed service, registry, browser, GPU or anti-cheat was exercised. Only this report was written.

### Additional bypasses

- **CONFIRMED: forged takeover.** Page-originated `toolize:takeover` with different detail stops engine/feed/word guards and enforcement timer (`extension/src/content/index.ts:74`, `extension/src/content/index.ts:84`). CSS remains, but attribute restoration ends (`extension/src/content/engine.ts:109`). Replace page-controlled retirement with extension-authenticated lifecycle/generation checks; random DOM details are not authentication.
- **CONFIRMED: synthetic DRM.** Untrusted `encrypted` events reach the handler (`extension/src/content/engine.ts:83`), permanently marking video dead/skip (`extension/src/content/video.ts:212`). Require browser-trusted DRM evidence, reject synthetic events and re-evaluate source/key changes. Genuine DRM stays explicitly unsupported, not presumed safe.
- **CONFIRMED: counterfeit health.** Authenticated users can write the general pipe (`companion/Toolize.Core/Pipe.cs:17`); caller-supplied browser/extension IDs update health (`companion/Toolize.Service/RequestHandler.cs:196`, `companion/Toolize.Service/RequestHandler.cs:205`). Native-host argv stamping is not service-side authentication (`companion/Toolize.NativeHost/Program.cs:18`). Reject health verbs on general control IPC; use a protected peer-validated broker bound to browser/session instances. Same-user telemetry is not attestation. Browser-wide keys also cannot prove every profile/session is guarded (`companion/Toolize.Service/Services.cs:116`).
- **CONFIRMED: sparse media verdicts.** One ordinary flagged paused still stays visible (`extension/src/content/video.ts:436`) and is not sampled again at that time (`extension/src/content/video.ts:267`). Cross-origin fallback samples 10/40/75% (`extension/src/offscreen/video-loader.ts:15`) then stops forever (`extension/src/content/video.ts:375`). Strict mode should cover flagged stills; refetch frames around actual playback, not certify a file from three points.
- **CONFIRMED: exemption/cache trust.** Trusted channels consume page-writable `data-tz-author` (`extension/src/content/video.ts:402`): independently verify exemptions or disclose that trust limit. Missing enforcement cache hides the shield (`extension/src/content/index.ts:61`): a policy-installed extension without its first handshake has no lease. Detect policy installation independently and require initial trusted contact; preserve standalone mode explicitly.

Clock, ID-collision, takeover, synthetic-DRM and backoff findings passed isolated in-memory probes; others are code-path deductions, not end-to-end demonstrations.

The service also uses one-sided wall-clock freshness (`companion/Toolize.Service/Services.cs:122`); migrate that deadline to monotonic time too.

**WRONG supporting claim:** red-team B6 says stopping the extension worker disables dynamic DNR. Installed dynamic rules persist across browser sessions/upgrades; a stopped worker loses updates/handlers, not the existing declarative rules.[DNR]

## 2. Architect: agreements and corrections

**SYSTEM-in-session DDA is feasible.** I retract the implication that helpers must share the user's killable identity. CreateProcessAsUser runs in its token's session: duplicate a SYSTEM primary token, set TokenSessionId, supply privileges/desktop access and `winsta0\default`. SYSTEM alone is insufficient setup. Microsoft's DDA sample attaches a capture thread to the input desktop; SetThreadDesktop fails after windows/hooks exist, so use a fresh thread.[CREATE], [SAMPLE], [DESKTOP]

**Do not follow UAC onto the secure desktop.** DuplicateOutput explicitly allows LOCAL_SYSTEM secure-desktop access, but that is capability, not product permission. Pause capture at lock/UAC transitions, report coverage loss, recreate on Default; handle RDP/fast-user-switching per session. Desktop switches invalidate duplication. Conversely, no acquired frame for three seconds can mean a perfectly static desktop: timeout is healthy, not a reason to relaunch.[DUP], [ACQUIRE]

**DDA-first deserves comparison, not decree.** Dirty/move rectangles and no capture border justify an early monitor-wide DDA candidate. WGC retains window-isolation/cross-check value; documented borderless consent requires a package capability. Hybrid capture needs the output-owning adapter; external ports/MUX changes defeat the assumption that iGPU/NPU keeps every dGPU asleep. Re-enumerate on topology changes. Classic DuplicateOutput converts to BGRA; DuplicateOutput1 negotiates formats, not automatically FP16 HDR. Validate actual format/color space and tone-map for SDR-trained inference; WGC documents an FP16 HDR pipeline.[BORDER], [HYBRID], [DUP1], [HDR]

**Kill resistance: agree narrowly.** SYSTEM-owned process/thread/job objects with deliberate DACLs, protected binaries and no leaked powerful handles resist standard-user terminate/suspend/injection rights. This is not PPL, crash immunity or an unobscurable overlay. Elevated debug privilege remains outside the guarantee. Minimize privileged message/GPU handling; a low-integrity label alone is not a sandbox. Audit restricted tokens, IPC and handle inheritance. A SYSTEM-only pipe distinguishes accounts, not individual trusted processes.[PROCESS], [DESKTOP]

**Compute/exposure estimates overreach.** Actual v3 figures are 8.512 ms/batch-1 and about 2.69 ms/image at batch-8, excluding warmup (`tools/safety-model/ensemble-audit.md:217`), not native DirectML/NPU measurements. WASM timing does not establish native CPU speed. Windows ML downloadable providers require 24H2+ and compatible drivers/operators; TOPS/another ResNet benchmark cannot establish support or latency.[WINML] The architect's 200-360 ms sweep at 0.5-1 Hz implies approximately **10-36% serialized compute duty**, inconsistent with its 1-3% game row. Separate queues reserve no compute. Measure transfers, both models, batching delay, watts and frame-time impact. A photo gate can miss flat/stylized explicit art: require forced audits and size-stratified recall.

Two-positive confirmation at 2 fps adds another 500 ms. Cover-new reacts after exposure and can miss proposed regions; 33-50 ms/three-refresh targets are experiments, not bounds. VMs/RDP become inspectable only when visible and capturable, not automatically solved threats. GetWindowDisplayAffinity supports cross-process queries but has documented success conditions; failure is not no exclusion. WCA and backend disagreements are diagnostics, not universal tamper proof. Legitimate privacy windows exclude capture too; automatic covers need explicit exceptions.[AFFINITY], [WCA]

**Anti-cheat: uncertainty, not clearance.** BattlEye distinguishes non-cheat overlays from cheats while retaining game-specific blocks/kicks. That does not establish that every topmost window is detected as ESP. The cited July-2026 Vanguard/OBS anecdote is not primary vendor evidence for Toolize compatibility. Opaque windows prove neither compatibility nor exclusive-fullscreen coverage. Avoid injection/process handles/input; seek vendor-supported validation. Throwaway-account tests cannot establish safety.[BE]

## 3. Red team: urgency without unsafe shortcuts

- **SafeSearch CNAMEs: agree, additional layer.** Google documents forcesafesearch.google.com, Microsoft strict.bing.com, DuckDuckGo safe.duckduckgo.com. Resolver-controlled mapping survives parameter overrides for participating DNS consumers without TLS MITM. Keep seven-engine DNR too. DNS cannot rewrite paths/POST bodies or constrain cached IPs/private DoH/tunnels. Handle names and A/AAAA/CNAME/HTTPS consistently; never alias every Google property. Learned browsing-derived domains remain browser-local unless privacy policy changes.[GOOGLE], [BING], [DDG]
- **Strip HTTPS/SVCB to block ECH: PARTLY.** Types 64=SVCB, 65=HTTPS. Suppressing discovery can disable ECH for cooperating clients without cached/out-of-band configurations, not universally. Records also carry routing/ALPN/address hints. Falsified NXDOMAIN can break A/AAAA; DNSSEC/downgrade-resistant clients can fail rather than expose SNI. ECH resists downgrade once attempted. Reject global stripping and the implication that ordinary ALE port/IP rules inspect TLS/QUIC hostnames. Private HTTPS tunnels remain a limit.[SVCB], [ECH], [WFP]
- **Service DACL: friction, not an admin boundary.** Standard users normally lack stop/delete already. Removing Administrators' SERVICE_STOP/DELETE while retaining WRITE_DAC/ownership permits restoring rights; broader denial risks recovery/updates without defeating elevated debug/offline access. Prefer least privilege, SCM recovery, persistent network policy and partner-held recovery. Reject automatic SafeBoot persistence as a substitute for account/boot controls.[SERVICE], [PROCESS]
- **Dual-Lock: future experiment, not today's fix.** Key AND 24-hour delay contradicts settled `CLAUDE.md` key-presence/no-timers semantics. Require explicit product approval/opt-in, restart/rollback-resistant pending changes, cancellation, key verification at commit and lost-key/emergency recovery. Never time-unlock without the key or delay security updates.
- **Close within 15 seconds: redesign the lease first.** Health stays fresh 90 seconds (`companion/Toolize.Service/Services.cs:36`), then 120-second grace plus ticks: roughly 210-230 seconds from last heartbeat before closing starts; Warn never closes. Sequential graceful closes can add five seconds each (`companion/Toolize.Service/WatchdogService.cs:156`). Shorten freshness and polling, cover immediately on verified loss, then close after bounded recovery. Installation, cold inference startup, updates, sleep, captive portals and corporate policy conflicts must not repeatedly destroy unsaved tabs. DLL fingerprints also flag legitimate CEF apps.
- **Foreground-only 2 fps: experiment, not PC-wide protection.** Other visible windows/monitors and between-sample flashes escape; whole-window squash hides thumbnails. Acrylic is unproven concealment, not zero-lag detection; opaque cover is the fallback. Reject synthetic PageDown. Rank threats by account-level reachability: page events/health spoofing, unmanaged/native mixed content and liveness first; private tunnels/VMs next; admin/alternate boot as explicit exclusions. No evidence establishes 20+ minutes of admin resistance or all tricks stopped. False lockouts are security failures too.

## 4. Reconciled architecture and phases

| Phase | Deliverable / exit gate |
|---|---|
| **P0: repair trust** | Event/DRM/cache/clock/overlay/video fixes; protected per-instance health and leases. Regress hostile pages, paused seeks, source transitions, disconnect/resume and update. Armed onboarding verifies readiness before destructive Close. |
| **P1: independent network** | SYSTEM owns signed/versioned public lists, last-known-good/rollback, loopback DNS and persistent transactional IPv4/IPv6 WFP. Test DoH/SafeSearch, VPN/split-DNS, tethering, caches, crashes and updater/recovery allowances. Retain DNR/browser-local learning. |
| **G0: parallel shadow study** | Shared DDA/WGC interface; local numbers-only study and synthetic cover harness. Both machines, multi-output/hybrid/HDR/UAC/RDP, idle and contention. Measure p50/p95/p99 exposure, size-based misses, false covers/hour, watts and frame-time regression; no explicit pixels saved/displayed. |
| **P2/G1: earned hardening** | Standard daily account, partner admin/recovery custody, audit-first app control, explicit VM/VPN/work exceptions. Validate SYSTEM-in-session/restricted inference. Regional proposals need concealment/tracking gates; whole-window covers remain fallback actuators, not sufficient thumbnail detection. Unsupported game/DRM/capture routes stay visibly unsupported or explicitly blocked. |
| **G2: optional expansion** | Independently evaluated localization/taxonomy and extension/native parity. Strict cover-new only after exposure/false-lockout gates. Cooldown/signing changes require explicit new decisions. |

**Concede:** early shadow studies, SYSTEM-in-session feasibility, regional proposals now. **Hold:** DOM stays primary; DNS/WFP cannot inspect every tunnel; admin/boot control is outside guarantees; capture cannot promise zero exposure. Adopt red-team urgency/resolver SafeSearch, not universal anti-bypass claims, deprecated proxies, blanket record stripping or recovery-hostile defaults. Keep content local, diagnostics content-free, service as authority, and no TLS interception.
